## Practical takeaway: make one draft easy to retrace

For the next allowed **local** Anycubic inspection, check that the receipt for the first small model can answer three questions: Which pinned source and variant did it come from? Which exact file and profile were inspected? Which facts were actually observed in the slicer, and which are still open (fit, adhesion, strength)? Use the existing receipt instead of creating a second record of the same part. If the capture fails again, record the failure rather than marking the inspection complete. No upload, fabrication or powered test is implied.
