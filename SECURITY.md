# Security policy

The repository maintainer triages vulnerabilities affecting the current `main` branch. Include the affected commit or source revision when you report a problem.

## Report a vulnerability privately

Sign in and look for **Report a vulnerability** on the [repository's Security Advisories page](https://github.com/LiamHoweth/RAFTEL/security/advisories). If that option is unavailable, contact [LiamHoweth](https://github.com/LiamHoweth) through an established private channel or open a public issue that only asks for a secure contact method. Keep suspected impact, reproduction details, credentials, and personal data out of public issues and pull requests while the maintainer assesses the report.

In a private report, describe the affected component, conditions, impact, and a minimal safe reproduction. Use the mock or an offline fixture when possible. If the issue concerns a dependency, include the exact version and relevant upstream advisory. Coordinate any public disclosure with the maintainer.

## Physical safety

Report a suspected safety defect using the same process if it involves sensitive details. Stop using an affected prototype and retain existing observations. The logical sorter has no physical driver. Follow the project's [safety and commissioning gates](arm-01/docs/safety.md) for hardware-related investigation.
